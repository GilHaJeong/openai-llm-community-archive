## Problem definition

The original homepage at `chatgpt.site` can be read by people, but some AI models cannot access it reliably. The project therefore uses GitHub and GitHub Pages as an additional public route.

This means GitHub is not merely a backup. It is the model-readable public canonical channel.

## Channel roles

```text
ChatGPT Sites
  -> existing human-facing site

GitHub repository
  -> model-readable canonical source and versioned archive

GitHub Pages
  -> human-readable GitHub-hosted website and simple text entry paths
```
