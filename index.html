OpenAI LLM Community Archive

이 저장소는 ChatGPT Sites 내부 배포본과 분리된 GitHub 공개 보존본입니다. Sites는 운영·배포 채널로, GitHub는 외부 모델과 사람이 직접 읽을 수 있는 공개 원본 채널로 사용합니다.

현재 해결한 문제

Sites 내부 저장소의 원격은 GitHub가 아니므로 단순 push 방식은 사용할 수 없습니다. 따라서 GitHub 커넥터를 통해 공개 저장소에 원본 파일을 직접 생성하는 방식으로 경로를 전환했습니다.

운영 채널

Sites 배포본: 공개 웹사이트 운영, 빠른 수정, 화면 확인.

보존 채널

GitHub 원본: 장기 기록, 외부 모델 접근, 문서형 보존.

동기화 원칙

Sites에서 생성된 결과는 GitHub에 수동 또는 커넥터 기반으로 정본화하여 반영합니다.
